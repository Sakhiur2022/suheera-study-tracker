প্রশ্ন ১: ফারেনহাইট থেকে সেলসিয়াস

সরল ক্রমস্টেটমেন্টের ধরন

ফারেনহাইট তাপমাত্রাকে সেলসিয়াস তাপমাত্রায় রূপান্তরের অ্যালগরিদম, ফ্লোচার্ট ও C প্রোগ্রাম ভাষায় রচনা কর এবং কী কী ধরনের statement ব্যবহার হয়েছে তা উল্লেখ কর।

সমাধান দেখোসমাধান লুকাও

অ্যালগরিদম

  1. শুরু করো।
  2. ফারেনহাইট তাপমাত্রা F ইনপুট নাও।
  3. সূত্র অনুযায়ী C = (F − 32) × 5 ÷ 9 গণনা করো।
  4. সেলসিয়াস তাপমাত্রা C প্রিন্ট করো।
  5. শেষ করো।

ফ্লোচার্ট

C প্রোগ্রাম

#include <stdio.h>

int main() {
    float f, c;                        // ঘোষণা (declaration)

    printf("Fahrenheit: ");            // আউটপুট
    scanf("%f", &f);                   // ইনপুট

    c = (f - 32) * 5.0 / 9.0;          // অ্যাসাইনমেন্ট

    printf("Celsius = %.2f\n", c);     // আউটপুট
    return 0;
}

নমুনা ইনপুট-আউটপুট

Fahrenheit: 98.6
Celsius = 37.00

ব্যবহৃত statement-এর ধরন

ধরন প্রোগ্রামের অংশ কাজ
প্রিপ্রসেসর নির্দেশ #include <stdio.h> ইনপুট-আউটপুটের হেডার ফাইল যুক্ত করে (এটি নির্দেশ, আসল statement নয়)
ঘোষণা (Declaration) statement float f, c; চলকের নাম ও ডেটা টাইপ নির্ধারণ করে
আউটপুট (Output) statement printf("Celsius = %.2f\n", c); পর্দায় ফলাফল দেখায়
ইনপুট (Input) statement scanf("%f", &f); কিবোর্ড থেকে মান নিয়ে f-এ রাখে
অ্যাসাইনমেন্ট (Assignment) statement c = (f - 32) * 5.0 / 9.0; গণনা করে ফল c-তে রাখে
রিটার্ন (Return) statement return 0; main ফাংশন শেষ করে প্রোগ্রাম সফলভাবে সমাপ্ত করে

মনে রাখো

  • সংক্ষেপে মনে রাখো: ঘোষণা → ইনপুট → অ্যাসাইনমেন্ট → আউটপুট → রিটার্ন।
  • সতর্কতা: 5 / 9 লিখলে দুটিই পূর্ণসংখ্যা হওয়ায় ফল 0 আসে। তাই 5.0 / 9.0 লিখতে হয়।

প্রশ্ন ২: ত্রিভুজের ক্ষেত্রফল

সরল ক্রম

ত্রিভুজের ক্ষেত্রফল নির্ণয়ের ফ্লোচার্ট, অ্যালগরিদম ও প্রোগ্রাম লিখ?

সমাধান দেখোসমাধান লুকাও

অ্যালগরিদম

  1. শুরু করো।
  2. ত্রিভুজের ভূমি (base) ও উচ্চতা (height) ইনপুট নাও।
  3. area = ½ × base × height গণনা করো।
  4. area প্রিন্ট করো।
  5. শেষ করো।

ফ্লোচার্ট

C প্রোগ্রাম

#include <stdio.h>

int main() {
    float base, height, area;

    printf("Base: ");
    scanf("%f", &base);
    printf("Height: ");
    scanf("%f", &height);

    area = 0.5 * base * height;

    printf("Area = %.2f\n", area);
    return 0;
}

নমুনা ইনপুট-আউটপুট

Base: 10
Height: 5
Area = 25.00

বিকল্প: তিন বাহু জানা থাকলে (হেরনের সূত্র)

#include <stdio.h>
#include <math.h>

int main() {
    float a, b, c, s, area;

    printf("Three sides: ");
    scanf("%f %f %f", &a, &b, &c);

    s = (a + b + c) / 2;
    area = sqrt(s * (s - a) * (s - b) * (s - c));

    printf("Area = %.2f\n", area);
    return 0;
}

নমুনা ইনপুট-আউটপুট

Three sides: 3 4 5
Area = 6.00

মনে রাখো

  • প্রশ্নে কোন তথ্য দেওয়া আছে তা দেখে সূত্র বাছাই করো: ভূমি ও উচ্চতা দেওয়া থাকলে ½ × ভূমি × উচ্চতা; তিন বাহু দেওয়া থাকলে হেরনের সূত্র, যেখানে s = (a + b + c) ÷ 2 এবং ক্ষেত্রফল = √(s(s−a)(s−b)(s−c))।
  • হেরনের সূত্রে sqrt() ব্যবহার হয় বলে #include <math.h> লাগে।

প্রশ্ন ৩: বর্গের ধারা (do-while)

do-while লুপধারা

1002 + 902 + 802 + … + n2 এই ধারাটির অ্যালগরিদম, flowchart ও Do while loop দ্বারা ধারাটির C ভাষার প্রোগ্রাম লিখ?

সমাধান দেখোসমাধান লুকাও

অ্যালগরিদম

  1. শুরু করো।
  2. n ইনপুট নাও (n হলো ধারার শেষ পদের ভিত্তি)।
  3. i = 100 এবং sum = 0 ধরো।
  4. sum = sum + i × i করো।
  5. i = i − 10 করো।
  6. i ≥ n হলে ধাপ ৪-এ ফিরে যাও, নইলে পরের ধাপে যাও।
  7. sum প্রিন্ট করো।
  8. শেষ করো।

ফ্লোচার্ট

C প্রোগ্রাম

#include <stdio.h>

int main() {
    int n, i = 100;
    long sum = 0;

    printf("Last base n: ");
    scanf("%d", &n);

    do {
        sum = sum + i * i;
        i = i - 10;
    } while (i >= n);

    printf("Sum = %ld\n", sum);
    return 0;
}

নমুনা ইনপুট-আউটপুট

Last base n: 70
Sum = 29400

মনে রাখো

  • ধারাটির পদগুলো ১০ করে কমছে, তাই i = i - 10। n = 70 দিলে যোগফল = 100² + 90² + 80² + 70² = 29400।
  • ধরে নেওয়া হয়েছে n ≤ 100 এবং n, 10-এর গুণিতক (যেমন 10, 20, … 100)।
  • do-while-এর বৈশিষ্ট্য: শর্ত লুপের শেষে পরীক্ষা হয়, তাই লুপের ভেতরের অংশ অন্তত একবার চলবেই। ফ্লোচার্টে এ কারণেই শর্তের রম্বস লুপ-বডির নিচে বসে।

প্রশ্ন ৪: তিন সংখ্যার মধ্যে বৃহত্তম

শর্ত (if)

তিনটি সংখ্যার মধ্যে সবচেয়ে বেশি তা নির্ণয়ের জন্য অ্যালগরিদম, flowchart, C-Programming লেখ?

সমাধান দেখোসমাধান লুকাও

অ্যালগরিদম

  1. শুরু করো।
  2. তিনটি সংখ্যা a, b, c ইনপুট নাও।
  3. max = a ধরো।
  4. b > max হলে max = b করো।
  5. c > max হলে max = c করো।
  6. max প্রিন্ট করো।
  7. শেষ করো।

ফ্লোচার্ট

C প্রোগ্রাম

#include <stdio.h>

int main() {
    int a, b, c, max;

    printf("Enter three numbers: ");
    scanf("%d %d %d", &a, &b, &c);

    max = a;
    if (b > max)
        max = b;
    if (c > max)
        max = c;

    printf("Largest = %d\n", max);
    return 0;
}

নমুনা ইনপুট-আউটপুট

Enter three numbers: 12 45 30
Largest = 45

মনে রাখো

  • কৌশল: প্রথম সংখ্যাকে আপাতত সবচেয়ে বড় ধরে নিয়ে বাকি দুটির সাথে একে একে তুলনা করা হয়েছে।
  • বিকল্প পদ্ধতি: nested if-else দিয়েও করা যায় (প্রথমে a ও b তুলনা, বিজয়ীকে c-এর সাথে তুলনা)। ফলাফল একই।
৫

প্রশ্ন ৫: ১ থেকে n পর্যন্ত যোগফল

for লুপধারা

1 + 2 + 3 + … + n এই ধারাটির অ্যালগরিদম, flowchart ও C ভাষায় Program লেখ?

সমাধান দেখোসমাধান লুকাও

অ্যালগরিদম

  1. শুরু করো।
  2. n ইনপুট নাও।
  3. sum = 0 এবং i = 1 ধরো।
  4. i ≤ n হলে পরের ধাপে যাও, নইলে ধাপ ৭-এ যাও।
  5. sum = sum + i করো।
  6. i = i + 1 করো এবং ধাপ ৪-এ ফিরে যাও।
  7. sum প্রিন্ট করো।
  8. শেষ করো।

ফ্লোচার্ট

C প্রোগ্রাম

#include <stdio.h>

int main() {
    int n, i, sum = 0;

    printf("Enter n: ");
    scanf("%d", &n);

    for (i = 1; i <= n; i++) {
        sum = sum + i;
    }

    printf("Sum = %d\n", sum);
    return 0;
}

নমুনা ইনপুট-আউটপুট

Enter n: 10
Sum = 55

মনে রাখো

  • যাচাইয়ের সূত্র: 1 + 2 + … + n = n(n + 1) ÷ 2। n = 10 হলে 10 × 11 ÷ 2 = 55, মিলে যায়।
  • for লুপের তিন অংশ (শুরু; শর্ত; পরিবর্তন) ফ্লোচার্টে আলাদা তিন জায়গায় দেখা যায়: i = 1 আগে, i ≤ n রম্বসে, i = i + 1 বডির শেষে।
৬

প্রশ্ন ৬: জোড় সংখ্যার যোগফল

for লুপধারা

2 + 4 + 6 + … + n এই ধারাটির অ্যালগরিদম, flowchart ও C-Program লিখ?

সমাধান দেখোসমাধান লুকাও

অ্যালগরিদম

  1. শুরু করো।
  2. n ইনপুট নাও (n হলো শেষ জোড় সংখ্যা)।
  3. sum = 0 এবং i = 2 ধরো।
  4. i ≤ n হলে পরের ধাপে যাও, নইলে ধাপ ৭-এ যাও।
  5. sum = sum + i করো।
  6. i = i + 2 করো এবং ধাপ ৪-এ ফিরে যাও।
  7. sum প্রিন্ট করো।
  8. শেষ করো।

ফ্লোচার্ট

C প্রোগ্রাম

#include <stdio.h>

int main() {
    int n, i, sum = 0;

    printf("Enter last term n (even): ");
    scanf("%d", &n);

    for (i = 2; i <= n; i = i + 2) {
        sum = sum + i;
    }

    printf("Sum = %d\n", sum);
    return 0;
}

নমুনা ইনপুট-আউটপুট

Enter last term n (even): 10
Sum = 30

মনে রাখো

  • পার্থক্য শুধু দুটি জায়গায়: শুরু i = 2 এবং বৃদ্ধি i = i + 2। বাকি সবই ৫ নম্বরের মতো।
  • যাচাইয়ের সূত্র: n জোড় হলে যোগফল = (n ÷ 2) × (n ÷ 2 + 1)। n = 10 হলে 5 × 6 = 30।

প্রশ্ন ৭: ফ্যাক্টরিয়াল নির্ণয়

for লুপগুণফল

একটি পূর্ণসংখ্যার factorial নির্ণয়ের জন্য Algorithm, flowchart, C-Program লেখ?

সমাধান দেখোসমাধান লুকাও

অ্যালগরিদম

  1. শুরু করো।
  2. পূর্ণসংখ্যা n ইনপুট নাও।
  3. fact = 1 এবং i = 1 ধরো।
  4. i ≤ n হলে পরের ধাপে যাও, নইলে ধাপ ৭-এ যাও।
  5. fact = fact × i করো।
  6. i = i + 1 করো এবং ধাপ ৪-এ ফিরে যাও।
  7. fact প্রিন্ট করো।
  8. শেষ করো।

ফ্লোচার্ট

C প্রোগ্রাম

#include <stdio.h>

int main() {
    int n, i;
    long long fact = 1;

    printf("Enter n: ");
    scanf("%d", &n);

    for (i = 1; i <= n; i++) {
        fact = fact * i;
    }

    printf("%d! = %lld\n", n, fact);
    return 0;
}

নমুনা ইনপুট-আউটপুট

Enter n: 5
5! = 120

মনে রাখো

  • n! = 1 × 2 × 3 × … × n। যেমন 5! = 120।
  • যোগের ধারায় sum শুরু হয় 0 দিয়ে, কিন্তু গুণে fact শুরু হয় 1 দিয়ে; 0 দিয়ে শুরু করলে সব গুণফল 0 হয়ে যায়।
  • 0! = 1: n = 0 হলে লুপ একবারও চলে না, তাই fact = 1-ই থেকে যায়। ঋণাত্মক সংখ্যার factorial হয় না।
  • ফল দ্রুত বড় হয় বলে long long ও %lld ব্যবহার করা হয়েছে (20! পর্যন্ত নিরাপদ)।

প্রশ্ন ৮: অ্যারে ব্যবহার করে দুটি সংখ্যার গড়

অ্যারেfor লুপ

Array ব্যবহার করে দুটি সংখ্যার গড় নির্ণয়ের অ্যালগরিদম, flowchart, C-Program লেখ?

সমাধান দেখোসমাধান লুকাও

অ্যালগরিদম

  1. শুরু করো।
  2. দুই উপাদানের অ্যারে a[2] ঘোষণা করো।
  3. sum = 0 এবং i = 0 ধরো।
  4. i < 2 হলে পরের ধাপে যাও, নইলে ধাপ ৭-এ যাও।
  5. a[i] ইনপুট নাও এবং sum = sum + a[i] করো।
  6. i = i + 1 করো এবং ধাপ ৪-এ ফিরে যাও।
  7. avg = sum ÷ 2 গণনা করো।
  8. avg প্রিন্ট করো।
  9. শেষ করো।

ফ্লোচার্ট

C প্রোগ্রাম

#include <stdio.h>

int main() {
    float a[2], sum = 0, avg;
    int i;

    for (i = 0; i < 2; i++) {
        printf("Enter number %d: ", i + 1);
        scanf("%f", &a[i]);
        sum = sum + a[i];
    }

    avg = sum / 2;

    printf("Average = %.2f\n", avg);
    return 0;
}

নমুনা ইনপুট-আউটপুট

Enter number 1: 10
Enter number 2: 15
Average = 12.50

মনে রাখো

  • অ্যারের সূচক (index) 0 থেকে শুরু হয়। দুই উপাদানের অ্যারে a[2]-এর উপাদান a[0] ও a[1]; তাই শর্ত i < 2।
  • গড় = সংখ্যাগুলোর যোগফল ÷ সংখ্যার পরিমাণ। দশমিক ফল পেতে float ব্যবহার করা হয়েছে।

প্রশ্ন ৯: বৃত্তের ক্ষেত্রফল

সরল ক্রম

বৃত্তের ক্ষেত্রফল নির্ণয়ের Algorithm, flowchart, C-Program লিখ?

সমাধান দেখোসমাধান লুকাও

অ্যালগরিদম

  1. শুরু করো।
  2. PI = 3.14159 ধরো।
  3. বৃত্তের ব্যাসার্ধ r ইনপুট নাও।
  4. area = π × r × r গণনা করো।
  5. area প্রিন্ট করো।
  6. শেষ করো।

ফ্লোচার্ট

C প্রোগ্রাম

#include <stdio.h>
#define PI 3.14159

int main() {
    float r, area;

    printf("Radius: ");
    scanf("%f", &r);

    area = PI * r * r;

    printf("Area = %.2f\n", area);
    return 0;
}

নমুনা ইনপুট-আউটপুট

Radius: 7

মনে রাখো

  • সূত্র: ক্ষেত্রফল = πr²। C-তে ঘাত চিহ্ন নেই, তাই r * r লেখা হয়েছে।
  • #define PI 3.14159 দিয়ে π-কে ধ্রুবক হিসেবে রাখা হয়েছে; এতে মান বদলাতে হলে একজায়গায় বদলালেই চলে।

প্রশ্ন ১০: অধিবর্ষ (Leap Year) নির্ণয়

শর্ত (if-else if)

একটি অধিবর্ষ (leap year) কিনা তা নির্ণয়ের Algorithm, flowchart, C-Program লেখ।

সমাধান দেখোসমাধান লুকাও

অ্যালগরিদম

  1. শুরু করো।
  2. বছর year ইনপুট নাও।
  3. year ÷ 400 নিঃশেষে বিভাজ্য হলে ধাপ ৬-এ যাও।
  4. নইলে year ÷ 100 নিঃশেষে বিভাজ্য হলে ধাপ ৭-এ যাও।
  5. নইলে year ÷ 4 নিঃশেষে বিভাজ্য হলে ধাপ ৬-এ যাও, না হলে ধাপ ৭-এ যাও।
  6. “Leap Year” প্রিন্ট করে ধাপ ৮-এ যাও।
  7. “Not Leap Year” প্রিন্ট করো।
  8. শেষ করো।

ফ্লোচার্ট

C প্রোগ্রাম

#include <stdio.h>

int main() {
    int year;

    printf("Enter a year: ");
    scanf("%d", &year);

    if (year % 400 == 0)
        printf("%d is a leap year.\n", year);
    else if (year % 100 == 0)
        printf("%d is not a leap year.\n", year);
    else if (year % 4 == 0)
        printf("%d is a leap year.\n", year);
    else
        printf("%d is not a leap year.\n", year);

    return 0;
}

নমুনা ইনপুট-আউটপুট

Enter a year: 2024
2024 is a leap year.

মনে রাখো

  • নিয়ম: ৪০০ দিয়ে বিভাজ্য হলে অধিবর্ষ; নইলে ১০০ দিয়ে বিভাজ্য হলে অধিবর্ষ নয়; নইলে ৪ দিয়ে বিভাজ্য হলে অধিবর্ষ।
  • পরীক্ষা করে দেখো: 2000 → অধিবর্ষ, 1900 → নয় (১০০ দিয়ে বিভাজ্য, ৪০০ দিয়ে নয়), 2024 → অধিবর্ষ, 2023 → নয়।
  • শর্তের ক্রম গুরুত্বপূর্ণ: বড় (৪০০) থেকে ছোটর (৪) দিকে পরীক্ষা করতে হয়, নইলে 2000 সালের মতো বছর ভুল ফল দেবে।
  • এক লাইনে: (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0)
